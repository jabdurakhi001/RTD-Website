# Truck Images

Upload your truck and trailer images here.

## How to use:

1. Upload images to this folder via GitHub web interface
2. Use the raw URL in your Google Sheet:
   `https://raw.githubusercontent.com/jabdurakhi001/RTD-Website/claude/build-truck-deal-website-j8K9R/images/YOUR-IMAGE.jpg`

## Naming convention:
- `volvo-vnl860.jpg`
- `freightliner-cascadia.png`
- `trailer-great-dane.jpg`
